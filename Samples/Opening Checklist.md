# Opening checklist

Everything the first person in needs to do before the doors open at **7:00**. It takes about 40 minutes, so start at 6:15.

## Before you switch anything on

- [x] Check the alarm panel shows no overnight alerts
- [x] Wash hands and put on an apron
- [ ] Read the notes left by last night's close
- [ ] Check the fridge log: it should read **between 1 °C and 4 °C**

## Ovens and coffee

1. Turn on both deck ovens and set them to *230 °C*.
2. Start the espresso machine. It needs 25 minutes to reach temperature.
3. Pull the proofed dough from the retarder and let it rest.

> If an oven shows error **E4**, don't reset it. Call Tom on 07700 900123 and use the Riverside oven for bread.

## Opening the till

| Drawer | Float | Notes |

./till open --store "Harbor Street" --float 230
