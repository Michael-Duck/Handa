# Handa brand

**Name:** handa, always lowercase in the wordmark. "Handa" in running text.
**Slogan:** Giving a hand, with your daily tasks.

**Mark:** a waving hand whose palm is a page. It says "help" and "documents" in one shape.
Use `icon.svg` on its own, or `banner.svg` / `banner-dark.svg` when there's room for the name.

**Colours**

| | Hex | Used for |
|---|---|---|
| Tangerine | `#FFA35C` | top of the icon gradient |
| Coral | `#F86F5B` | the main brand colour, buttons, highlights |
| Rose | `#EC4868` | bottom of the icon gradient |
| Ink | `#1F1A2E` | the wordmark and text on light backgrounds |
| Cream | `#FFF4EC` | the wordmark on dark backgrounds, soft panels |

**Type:** the wordmark is Nunito Black (converted to outlines, so no font is needed).
Inside the app, text uses the Mac's own SF Pro Rounded.
